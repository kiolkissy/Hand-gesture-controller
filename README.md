# Gesture-Controlled 3D Carousel

A hand gesture-controlled 3D carousel built with MediaPipe Hands and vanilla JavaScript. Navigate through cards using simple flick gestures.

## Features

- **Hand Gesture Navigation**: Flick left or right to navigate through cards
- **3D Card Display**: Cards elevate in the Z-axis when active
- **Real-time Hand Tracking**: Uses MediaPipe Hands for accurate gesture detection
- **Responsive Design**: Clean, modern UI with smooth animations

## Gestures

- 👈 **Flick Left**: Navigate to previous card
- 👉 **Flick Right**: Navigate to next card

## Technologies

- HTML5
- CSS3 (3D transforms, animations)
- JavaScript (ES6+)
- MediaPipe Hands API

## How to Use

1. Open `index.html` in a modern web browser
2. Allow camera access when prompted
3. Open your hand and make flick gestures left or right to navigate

## Installation

No installation required! Simply clone the repository and open `index.html` in your browser:

```bash
git clone https://github.com/kiolkissy/hand-gesture-volume-control.git
cd hand-gesture-volume-control
# Open index.html in your browser
```

## Browser Compatibility

Works best in:
- Chrome/Edge (recommended)
- Firefox
- Safari

Requires camera access for hand tracking.
